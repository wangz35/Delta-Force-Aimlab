# Aim // Range

一个使用 Unreal Engine 5 C++ 构建的第一人称瞄准训练原型。它不使用任何第三方游戏的素材、地图或角色，只借鉴现代战术射击的清晰反馈与训练节奏。

## 已实现

- WASD 自由移动、鼠标瞄准、左键命中扫描射击；射击不会产生后坐力
- `Left Ctrl` 低姿态滑铲；训练时可持续转向以练习滑铲 Tracking
- 六个随机尺寸、随机速度与随机路线的目标，混合横移、低位滑铲、跳跃急停变向（jump-pull）三种轨迹
- 60 秒训练回合、命中数、射击数、命中率、平均/最近反应时间
- 回合结束复盘与 `R` 一键重开
- C++ Canvas HUD、程序化靶场与基础命中判定；无需模板资产

## 启动

1. 双击 `AimTracker.uproject` 并在 Unreal Engine 5.8 中生成项目文件。
2. 首次打开时选择构建 `AimTrackerEditor`。
3. 在编辑器点击 Play，即可开始训练。

引擎路径：`D:\UE_5.8`。
